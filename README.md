# Juego de Preguntas (prueba_codex)

Este proyecto implementa un juego de trivia en español usando tecnologías web modernas.

- **React 18** para construir la interfaz en componentes.
- **TypeScript** para darle tipado al código de los componentes.
- **Bootstrap 5** y **Bootstrap Icons** para los estilos y algunos iconos.

Simplemente abre `index.html` en un navegador reciente para comenzar a jugar.
